## Решения
- Публикация: GitHub Pages из папки `/docs` ветки `main`. `docs/` коммитится.
- `node build.js` → `docs/` (компании без «_»). `node build.js --test` → `preview/` (все, включая «_»); тестовая компания никогда не попадает в `docs/`.
- `.gitignore`: preview/, checks/, node_modules/, .DS_Store, Thumbs.db.
- `docs/index.html` — пустая страница с noindex, плюс `docs/.nojekyll`.
- На проектном сайте GitHub Pages (username.github.io/repo) robots.txt поисковики не читают → основная защита демо — `<meta name="robots" content="noindex, nofollow">` на каждой странице. robots.txt в `docs/` всё равно кладём.
- `docs/robots.txt` статичный `Disallow: /`. Не генерируем по компаниям: список слагов в robots.txt = публичный каталог демо (правило 7).
- Оплатившие клиенты (demo=false) публикуются отдельно, не в этом репозитории. build.js предупреждает, если demo=false попадает в docs/.
- `_test` без `TEST_WA` не собирается — так и задумано; фиктивный phone не добавляем (tel: на выдуманный номер может набрать реального человека).
- Автор git (только этот репозиторий): Vladislav622 <348251430+Vladislav622@users.noreply.github.com>. Личная почта не должна попасть в репозиторий.
- Шаблон: `{{key}}` — текст с экранированием, `{{{key}}}` — готовый HTML, `<!--if:key-->…<!--/if:key-->` — блок вырезается из HTML при пустом значении. Неизвестная метка → сборка падает.
- style.css и app.js копируются в каждую папку компании (страница самодостаточна).
- `.gitattributes`: `* text=auto eol=lf`.
- Коммит после каждого принятого шага: «шаг N: …».
- Node.js ≥ 20 (на машине v24.22.1).
