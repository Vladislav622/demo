## Решения
- Публикация: GitHub Pages из папки `/docs` ветки `main`. `docs/` коммитится.
- `node build.js` → `docs/` (компании без «_»). `node build.js --test` → `preview/` (все, включая «_»); тестовая компания никогда не попадает в `docs/`.
- `.gitignore`: preview/, checks/, node_modules/, .DS_Store, Thumbs.db.
- `docs/index.html` — пустая страница с noindex, плюс `docs/.nojekyll`.
- На проектном сайте GitHub Pages (username.github.io/repo) robots.txt поисковики не читают → основная защита демо — `<meta name="robots" content="noindex, nofollow">` на каждой странице. robots.txt в `docs/` всё равно кладём.
- `docs/robots.txt` статичный `Disallow: /`. Не генерируем по компаниям: список слагов в robots.txt = публичный каталог демо (правило 7).
- Оплатившие клиенты (demo=false) публикуются отдельно, не в этом репозитории. build.js предупреждает, если demo=false попадает в docs/.
- `_test` без `TEST_WA` не собирается — так и задумано; фиктивный phone не добавляем (tel: на выдуманный номер может набрать реального человека).
- Автор git (только этот репозиторий): Vladislav622 <348251430+Vladislav622@users.noreply.github.com>. Личная почта не должна попасть в репозиторий.
- Шаблон: `{{key}}` — текст с экранированием, `{{{key}}}` — готовый HTML, `<!--if:key-->…<!--/if:key-->` — блок вырезается из HTML при пустом значении. Неизвестная метка → сборка падает.
- `.gitattributes`: `* text=auto eol=lf`.
- Иконки техники и интерфейса — inline SVG в build.js (KIND_PATHS, UI), контур 2px через vector-effect: non-scaling-stroke.
- Скриншоты и проверки — `node tests/screens.js <slug>`: headless Edge/Chrome через DevTools-протокол, без npm (Node ≥ 22).
- `city_in` («в Караганде») → «Аренда спецтехники в Караганде»; без него заголовок «Аренда спецтехники», ниже «{city} · {name}».
- Чистые функции (plural, fmtNum, цена, текст заявки) — в template/app.js, экспорт через module.exports; их используют build.js и tests/price.test.js.
- Имя в заявке необязательно: строка «Имя:» выводится, только если заполнено.
- Зона доставки обязательна, если zones не пустой (иначе ориентир без доставки занижен).
- style.css и app.js встраиваются в index.html при сборке: один запрос вместо трёх (Slow 3G: 2.3 с с gzip вместо 4.7 с). tests/screens.js отдаёт файлы с gzip, как GitHub Pages.
- v2: основной канал заявок — WhatsApp (работаем по городам Казахстана). Нет channel → whatsapp, если он задан; Telegram — запасной, только если у компании нет WhatsApp; нет мессенджеров → tel:. Кнопки, окно заявки, примеры и скриншоты по умолчанию — для WhatsApp.
- v2: статус позиции machines[].status = free | busy | confirm; available:true/false понимаем (→ free/busy) с предупреждением.
- v2: имя и телефон в форме необязательны (заявка уходит из мессенджера клиента); введённый телефон — ≥ 10 цифр.
- v2: сумма точная («30 600 ₸»), если нет rate_to и delivery_to; иначе диапазон. Заменяет правило PROMPT_01 «от X ₸».
- v2: общие фото по виду техники — assets/stock/<kind>.jpg (Unsplash License, источники в assets/stock/SOURCES.md), подпись «Фото для примера»; build.js копирует компании только нужные.
- design/ и PROMPT_*.md — в .gitignore: чужие скриншоты и внутренние промпты в публичный репозиторий не идут.
- Stock-фото: без рекламы других компаний (прокатчиков); логотип производителя допустим. Скриншоты в отчётах — по витрине _sample.
- Telegram: t.me/<username>?text=<draft_text> поддерживается официально (core.telegram.org/api/links, «Public username links»); заявка дополнительно копируется в буфер с подсказкой.
- Контакты тестовых папок — только из окружения: TEST_WA, TEST_TG, TEST_CHANNEL.
- PROMPT_01 вычищен из всей истории (filter-branch, до первого push); автор коммитов — noreply.
- Демо-панель: docs/<slug>/admin/index.html (template/admin.html + admin.css + admin.js, встраиваются при сборке), плашка демо и noindex всегда, ссылки с сайта нет. Пароля нет — данные только в браузере.
- Data-слой (app.js): mergeOverrides(конфиг, изменения) + Store (localStorage, ключ specsite-demo:<slug>, всё в try/catch) + getCompanyData(). Сайт и панель берут данные только через него; при наличии изменений сайт перерисовывает карточки, список техники и канал. После первой оплаты меняется только Store.
- Адрес панели — <slug>/admin/: «секретный» адрес в публичном репозитории ничего не скрывает, защита рабочей версии — пароль на сервере.
- Новая цена в панели одна («за час»): при её изменении диапазон rate_to снимается.
- Рабочая версия панели — с паролем на стороне сервера; ключей и паролей в коде страницы быть не должно.
- Коммит после каждого принятого шага: «шаг N: …».
- Node.js ≥ 22 (на машине v24.22.1): tests/screens.js использует глобальные fetch и WebSocket.
