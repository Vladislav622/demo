Как пользоваться
  • Цена: откройте «Цены и статусы», впишите число без копеек и нажмите «Сохранить». Пустое поле — на сайте «цена по запросу».
  • Техника на объекте: нажмите «Занята» и «Сохранить» — её нельзя будет выбрать в заявке.
  • Освободилась — «Свободна» и «Сохранить».
  • Заявка не пришла: проверьте номер в блоке «Контакт для заявок» внизу.
  • Затем нажмите «Отправить тестовую заявку себе» — должен открыться WhatsApp с вашим номером.
