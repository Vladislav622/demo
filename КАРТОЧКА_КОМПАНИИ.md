# Карточка компании: что заполнить и где найти

Главное правило: **нет данных — поле пустое** (`""`, `null`, `[]`). Блок на странице тогда просто не появится. Ничего не додумывать: ни цен, ни отзывов, ни «15 лет на рынке».
После заполнения — `node build.js check`.

## Основное
| Поле | Что это | Где найти | Если нет |
|---|---|---|---|
| `slug` | адрес страницы, латиница через «-» | придумать из названия: `stroy-tehnika` | — обязательно |
| `demo` | `true` — плашка «Демо-концепт…» и noindex | для показа до оплаты всегда `true` | — |
| `name` | название как на вывеске | 2ГИС (заголовок карточки), шапка Instagram, сайт | — обязательно |
| `tagline` | короткая строка под названием | описание в 2ГИС / Instagram | пусто |
| `city`, `city_in` | «Караганда», «в Караганде» | адрес в 2ГИС | пусто — заголовок без города |
| `address` | адрес базы / офиса | 2ГИС | пусто |
| `schedule` | «Ежедневно 8:00–20:00» | часы работы в 2ГИС | пусто |
| `logo` | файл в `img/` (PNG, SVG, JPG) | аватар Instagram, сайт | пусто — буква названия в цветном квадрате |
| `colors.primary`, `colors.accent` | фирменные цвета `#RRGGBB` | логотип, вывеска, сайт | пусто — цвета шаблона; контраст сборка поправит сама |

## Контакты (хотя бы один)
| Поле | Что это | Где найти | Если нет |
|---|---|---|---|
| `whatsapp` | только цифры: `77011234567` | кнопка WhatsApp в 2ГИС / Instagram, «WhatsApp» в шапке сайта | пусто |
| `telegram` | username без @ | ссылка t.me/… в профиле | пусто |
| `channel` | `whatsapp` или `telegram` — куда идут заявки | WhatsApp, если он есть | пусто — WhatsApp, потом Telegram |
| `phone` | телефон для звонка | 2ГИС | пусто; если нет и мессенджеров — сайт не собрать |

Не вписывать номер, если не уверены, что он принадлежит компании: заявки уйдут постороннему человеку.

## Техника (`machines`, хотя бы одна позиция)
| Поле | Что это | Где найти | Если нет |
|---|---|---|---|
| `id` | латиница через «-»: `avtokran-25` | придумать из названия | — обязательно |
| `title` | «Автокран 25 т» | прайс, посты в Instagram, раздел «Товары и услуги» в 2ГИС | — обязательно |
| `kind` | вид для иконки и общего фото: excavator, crane, dump_truck, loader, mini_loader, manipulator, aerial_platform, bulldozer, roller, tractor, other | по названию | `other` |
| `purpose` | для каких работ | описание услуги | пусто |
| `rate_from`, `rate_to` | цена «от» и «до», целые числа | прайс в 2ГИС, сайт, сторис «Цены» | `null` — «цена по запросу» |
| `unit` | «час», «смена», «день», «рейс» | рядом с ценой | — обязательно, обычно «час» |
| `min_units` | минимальный заказ | «минимум 4 часа» в прайсе | `null` |
| `status` | `free` / `busy` / `confirm` | — | `confirm` (требует подтверждения), если не знаете |
| `photo` | файл в `img/` — **только фото этой компании** | их Instagram, 2ГИС | пусто — общее «Фото для примера» |

## Дополнительно (всё необязательно)
| Поле | Что это | Где найти |
|---|---|---|
| `hero_title` | заголовок первого экрана, слова в `*звёздочках*` — акцентным цветом | лучше оставить пустым: будет стандартный |
| `hero_photo` | большое фото первого экрана | их лучшее фото техники на объекте |
| `delivery_time_text` | «от 2 ч» — как быстро подают | сторис, описание, отзывы |
| `park_note` | одна фраза о парке техники | описание компании |
| `features` | до 4 преимуществ `{icon, title, text}`, icon: park, clock, operator, calendar, shield, truck | только то, что компания сама о себе пишет; пустые записи удалить |
| `about` | абзац «О компании» | раздел «О компании» на сайте / в 2ГИС |
| `reviews_summary` | пересказы отзывов **без имён**, 1–3 строки | отзывы в 2ГИС — своими словами |
| `source_2gis` | ссылка на карточку 2ГИС | адресная строка браузера |
| `zones` | зоны доставки `{title, delivery_from, delivery_to}` | прайс доставки; нет — `[]`, поле зоны пропадёт из формы |
| `currency` | валюта — **обязательно**, обычно «₸» | — |
| `price_note` | пометка под ценой: «итог подтвердит менеджер» | — |
| `og_title`, `og_description` | заголовок и описание превью ссылки в мессенджерах | обычно пусто — возьмутся заголовок и описание страницы |

Пустые записи-заготовки в `features`, `machines`, `zones` удалите, если заполнять нечем.
